Introdução

Este projeto demonstra o PyScript executando Python diretamente no navegador via Pyodide. Abra esta página com um servidor HTTP local (veja o README) — a primeira carga exibe o progresso do Pyodide (pode levar alguns minutos).

Cada seção carrega um arquivo examples/*.py com <script type="py"> ou, no exemplo 9, <script type="py-editor">. NumPy, Matplotlib e pyjokes são baixados sob demanda nos exemplos 4, 5 e 8; a janela modal mostra o progresso do download e inicialização do Pyodide.
