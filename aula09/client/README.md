# Aplicação cliente (React) - aula09

A aplicação cliente desta aula é **a mesma da [aula07](../../aula07/client/README.md)**, sem nenhuma alteração no código-fonte.

Nesta aula as alterações estão concentradas no lado servidor (observabilidade com OpenTelemetry e Grafana LGTM). Consulte o [README.MD do server](../server/README.MD) para ver o conteúdo da aula.

Para a explicação completa da aplicação cliente (upload da imagem do produto com RustFS), consulte o [README.md do client da aula07](../../aula07/client/README.md).

## Executando a aplicação

```bash
npm install
npm run dev
```
